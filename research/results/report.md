## 三、假設檢定與核心問題

### H1 / Q1 — 0050 黑K 是否降低 2330 平均買進成本？

- 策略 C（0050 黑K）平均買進成本：**241.60**
- 基準 B（不看漲跌、平均分散）平均買進成本：**241.74**
- 差異：**-0.06%** → **支持 H1（成本較低）**

### H2 / Q2 — 成本優勢是否大於 Cash Drag（現金閒置成本）？

- C 平均閒置現金：**31,167**，最大閒置現金：**95,000**，Cash Drag Ratio：**0.97%**
- C 最終資產：**17,569,560**　vs　B 最終資產：**17,639,533**
- 淨效果（C 相對 B）：**-0.40%** → **Cash Drag 抵銷了成本優勢**

### H3 / Q3（核心）— 0050 是否能作為 2330 有效的 Timing Signal？

- 用 0050 訊號 (C) 最終資產 **17,569,560** / IRR **+18.24%**
- 用 2330 自己訊號 (E) 最終資產 **17,584,460** / IRR **+18.25%**
- 不看漲跌 (B) 最終資產 **17,639,533** / IRR **+18.31%**
- 每月一次 (A) 最終資產 **17,791,772** / IRR **+18.45%**
- 判定：**0050 黑K 未展現優於不擇時買進的擇時能力**
