# 0050 黑K 作為台積電（2330）定期定額進場訊號 — 回測研究

本專案實作研究設計中的策略與比較組，量化驗證下列問題：

> 在無法預知未來、固定每月投入資金的前提下，利用市場回檔（**0050 黑K**）作為
> 進場訊號，是否能改善台積電（**2330**）長期定期定額的績效，且其收益是否足以
> 抵銷等待期間的現金閒置成本（**Cash Drag**）？

本研究**不預測最低點、也不最佳化參數**，只在固定資金框架下比較「訊號」的效果。

---

## ⚠️ 關於資料（重要）

這個執行環境的網路政策**封鎖了所有外部股價來源**（Yahoo / Stooq / 證交所 /
FinMind 皆回傳 403），因此**無法自動下載真實股價**。

* 若 `data/0050.csv`、`data/2330.csv` 不存在，`run.py` 會自動產生一份
  **合成（synthetic）示範資料**，讓整條回測流程可以立即跑起來、報表格式可被檢視。
* 合成資料只保留兩個真實特徵（2330 長期報酬 > 0050、兩者高度相關），**數字純屬
  示範，不能作為投資結論**。報表最上方會標示紅色警告。
* **要得到真實結論**：把 `data/0050.csv`、`data/2330.csv` 換成真實**還原**股價
  （格式見 `data/README.md`），刪除 `data/.synthetic`，再重跑 `python run.py`。

## 策略與比較組

所有策略共用**同一套資金框架**（見下），差別只在「買進訊號 / 節奏」：

| 代號 | 說明 | 買進條件 |
|---|---|---|
| A | 每月一次投入 50,000 | 每月第一個交易日開盤，一次投入 50,000 |
| B | 平均分散（不看漲跌）| 每月挑 10 個平均分布的交易日，各投入 5,000 |
| **C = G1** | **0050 黑K（核心）** | 0050 今收 < 昨收 → **隔日開盤**買 2330 |
| D = G4 | 0050 下跌 ≥ 1% | 0050 跌幅 ≥ 1% → 隔日開盤買 |
| E | 2330 自己黑K | 2330 今收 < 昨收 → 隔日開盤買 |
| G2 | 0050 連跌 2 天 | 連續兩根黑K → 隔日開盤買 |
| G3 | 0050 連跌 3 天 | 連續三根黑K → 隔日開盤買 |
| G5 | 0050 跌破 MA20 | 0050 收盤 < 自身 20 日均線 → 隔日開盤買 |
| G6 | 0050 黑K 且 2330 黑K | 兩者同日皆黑K → 隔日開盤買 |
| G7 | 0050 黑K + 2330 回檔 | 0050 黑K 且 2330 距 60 日高點回檔 ≥ 5% → 隔日開盤買 |

> **Freshness（G7）定義**：研究設計未給精確定義，本專案將其操作化為
> 「2330 距 trailing 60 日最高收盤的回檔幅度」，門檻預設 5%（可調）。

### 共用資金框架（engine.py）

* 每月第一個交易日，現金池 **+50,000**。**未用完無上限累積**（carryover）。
* 每次訊號買進固定 **5,000**，於**訊號隔一交易日開盤**成交（避免未來函數）。
* 訊號買進採 **all-or-nothing**：現金池不足 5,000 就跳過，預算留在池中累積
  → 這正好重現「當月預算用完就停 / 未用完就累積」的規則，Cash Drag 也由此自然產生。
* 閒置現金預設利率 **0%**（純 Cash Drag）；可用 `--idle-rate` 調整。
* 預設允許**零股/碎股**；`--lot-size 1000` 可強制整股。

> 關於「每月最多 10 次 / 已投入 50,000 就停」與「八月可用 70,000」看似矛盾之處：
> 研究設計以具體數字（七月剩 20,000 → 八月可用 70,000）說明**累積現金池**語意，
> 因此本實作採**累積現金池**（每月 +50,000、無上限累積、每買 −5,000），其結果與
> 該範例完全一致。

## 評估指標（metrics.py）

| 類別 | 指標 |
|---|---|
| 績效 | Final Assets、Multiple、CAGR（以總投入為基準）、**IRR（money-weighted / XIRR）** |
| 成本 | 平均買進成本（以股數加權）、平均成交價格（單純平均）|
| 資金效率 | 平均閒置現金（時間加權）、最大閒置現金、Cash Drag Ratio |
| 交易統計 | 買進次數、每月平均買進次數、平均等待（交易日）|
| 風險 | 最大回撤 MDD、年化波動度 |

重點方法：

* **公平比較的關鍵**：所有策略的「投入承諾」都是每月 50,000（`Total Contributed`
  相同）。沒被部署的錢留在現金池（0% 利息），因此 Cash Drag 會誠實反映在
  `Final Assets` 與 `IRR` 上。
* **IRR** 以「每月 −50,000 現金流出 + 期末 +最終資產」解 XIRR（年化）。
* **風險指標**用**時間加權報酬曲線**（每日剔除當日外部投入後計算報酬）計算，
  避免定期投入的資金流入被誤當成報酬而扭曲 MDD / 波動度。

## 對應研究問題

* **H1 / Q1**：C 的平均買進成本是否低於 B（不擇時）？
* **H2 / Q2**：C 的最終資產是否 ≥ B？（成本優勢是否勝過 Cash Drag）
* **H3 / Q3（核心）**：以 0050 訊號（C）是否勝過不擇時（B）、且不輸給用 2330
  自身訊號（E）？三者比較即可判斷「0050 能否作為 2330 的有效 Timing Signal」。

`results/report.md` 會依實際數字自動給出上述三題的判定。
